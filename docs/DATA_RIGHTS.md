# Data rights and public-release boundary

Reviewed on 26 October 2026 against the [SaluteLazio legal notice](https://salutelazio.it/it/note-legali) and the [Regione Lazio legal notice](https://www.regione.lazio.it/note-legali).

The notices contain restrictions on copying and redistributing portal content, subject to applicable exceptions, specific conditions or permission. Public accessibility alone is not a blanket redistribution licence. These notices do not establish the licence of every independently published dataset.

This public source edition addresses that redistribution concern by including **only generated fictional facility records**. It does not distribute the original facility catalogue, source exports, HTML caches, seed documents, observation databases, old validation reports or the original Git history. Source links identify integration targets; they do not imply permission or official endorsement.

The synthetic catalogue is labelled in the data and API responses. Backend collectors remain disabled while it is loaded, and the poller refuses it. Explicit acquisition scripts and optional AI/Telegram integrations are documented separately and are not part of the default local demonstration.

Before using or publishing real records, obtain the applicable dataset licence or specific authorization, check attribution and reuse conditions, and review the intended processing and deployment. Do not simply change the synthetic flag or assume that private storage, a disclaimer or attribution grants permission. No authorization from Regione Lazio has been requested or obtained as part of this release.

The source code is a separate academic software contribution. This note is the technical publication boundary adopted for this edition, not a legal clearance of every future use or a clinical certification.
