# Project scope

LazioFlow demonstrates Italian request parsing, deterministic safeguards, explicit confirmation and transparent facility ranking. The original academic project integrated Lazio healthcare sources. This edition ships only generated fictional facilities and preserves no original Git history.

Implemented components include a FastAPI backend, Telegram interface, structured optional LLM parsing with rules fallback, compatibility rules, hierarchical ranking, freshness/trend handling, source adapters and tests.

The public catalogue is for software demonstrations only. Real-source data, operational history and old evaluation reports are excluded. Dashboard features, clinical triage, forecasting and statistical weather-to-health inference are outside scope.

See the root [README](../README.md) for setup, [data notes](../data/README.md) for the synthetic catalogue and [operations](OPERATIVITA.md) before connecting external services.
